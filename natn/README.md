# natn/ — النتن

The stench.

git, Linear, GitHub. Each is translated here into a shape the constitution
already had a word for. Iksīr does not reach into these. They reach up and
comply.

## The rule

Nothing in `natn/` may be imported by `src/daemon/`, `src/alat/`, or
`src/hum/`. An adapter may name `src/hayula/` and `src/types.ts`, nothing
else. A test enforces it.

## What lives here

|---|---|---|
| `hayula-git/` | git | `Hayula` |
| `hayula-nass/` | a markdown file | `Hayula` |
| `fasl-github/` | GitHub | `Fasl` |
| `wasfa-linear/` | Linear | a mirror, for those who want one |
