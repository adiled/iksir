# Iksīr v1 — the harness, grounded in the hum network

No recipe. hum's recipes are its own playground for children; iksir v1 is
itself a harness, adult, speaking thrum natively. Nothing here changes hum.
Wire conformance is pinned, not discovered:

- `THRUM_VERSION = "0.7.0"` (generated `thrum-clients/ts/chi.ts`)
- socket `$HUM_THRUM_SOCK ?? $XDG_RUNTIME_DIR/hum/thrum.sock`
- hello per `hives/README.md` §2 + `hives/openai-server/src/thrum.ts`:
  `bee`, `hive`, `hid` (`fbee_`/`wbee_` + sha256hex(ed25519pub),
  key at `$XDG_STATE_HOME/hum/bees/<kind>.key`), `version`,
  `protoVersion`, `chis`, `tools` [{name, description, inputSchema}],
  `provides`, `propensity`, `source`
- chi registry per `thrum-core/src/chi.rs` (mirrored in `hum/wire.js`)

OpenCode is assumed gone. Deno is knifed. Node LTS, zero dependencies,
`node --test` is the whole toolchain.

## The shape

```
 Telegram                                    thehum (signed chi log — Sijill for free)
    │ chat                                        ▲ every tone lands here, signed
    ▼                                             │
 (mind) hybrid bee ──chi:prompt──► [humd] ──spawn──► murshid cell (claude-repl today,
    │                              │ │ │               iksir's own hive tomorrow)
    │                    ToolCall   │ │ │ chunk/finish
    │                  ┌────────────┘ │ └─────────────┐
    │                  ▼              │               ▼
 (tools) forager ──ToolResult──► [humd] ──routes──► cell        (drone: raqib rides
    │ code_* (real)  ▲ by toolName                  │             as Classifier)
    │ mur_far_*      └──────────────────────────────┘
    │                                               permission-ask ──► (mind) ──► Telegram
    │                                               release-permit ◄── inline approve/deny
 (hayat) bee ──gossip-publish iksir/debrief──► mesh
```

One furnace: (mind) commissions exactly one cell at a time. humd would
happily run N; iksir says one. That law lives in `bees/mind.js`, nowhere else.

## Bee inventory (this repo)

| bee | hive | role | speaks |
|---|---|---|---|
| `bees/tools.js` | `iksir-tools` | forager | `hello, tool-call, tool-result, error` — advertises `code_*` + `mur_far_*`, answers `tool-call` with `tool-result` |
| `bees/mind.js` | `iksir-mind` | hybrid worker+forager | polls Telegram (forager side); munadi→arraf→munaffidh→saail/mumayyiz chain; commissions cells via `prompt`; renders `permission-ask` to Telegram, returns `release-permit` |
| `bees/hayat.js` | `iksir-hayat` | forager | `gossip-publish` debriefs on `iksir/debrief`; answers `curate` |

Shared: `hum/wire.js` (registry, envelope, framing, sigil/rid/dusk/wane),
`hum/identity.js` (stable hid, byte-identical to hum's Rust + TS hives),
`hum/bee.js` (socket, hello, dispatch, reconnect). `codeintel/` is the
v0 indexer/query engine ported off Deno (`deno doc` extraction dropped —
regex is now the only extractor; it already covered non-exported symbols).

## What died

- `src/opencode/*`, the `opencode.server` schema block — humd is the runtime.
- `src/mcp/iksir-mcp.ts` protocol scaffolding — humd brokers tools natively.
- SQLite event-bus IPC — thehum is the bus and the audit.
- Deno itself — `deno.json`/`src/*.ts` stay on the branch as reference only.

## What iksir keeps (the moat)

One flame. Dhahab/khabath filtering (saail/mumayyiz — heuristic in v1,
model-backed the moment cells are commissionable). Kitab al-Hikmah
(wisdom across works, replayed off backfill/wane — not conversation
memory). The murshid incantations. The tongue.
